# 原型內容目錄

本目錄只記錄目前原型已經有的內容，以及可供後續規劃的概念項目。概念項目不代表已實作或已決定正式版玩法。

## 方塊

| 方塊 | 分類 | 原型用途與現況 |
|---|---|---|
| 草地 | 地表 | 覆蓋多數島嶼地表，可在物品欄選取、挖除與放置。 |
| 石磚 | 岩地／建材 | 澎湖地表使用石材色塊；玩家可用來建造。 |
| 紅磚 | 建材 | 台中起始街角紅磚店屋牆面，也可自由建造。 |
| 柏油 | 街道 | 起始建築旁鋪設街道路面，可延伸街景。 |
| 木材 | 建材 | 第二間起始店屋的牆面，也可自由建造。 |
| 消波塊 | 海岸 | 起始海岸放有一排消波塊，玩家也可自由放置。 |
| 泥土 | 地層 | 用於島嶼表層以下的地層，並可由玩家選取建造。 |
| 紅瓦 | 屋頂 | 起始店屋屋頂材質，也可自由建造。 |
| 水泥 | 人行空間／建材 | 用於起始街道地坪與店屋地板，也可自由建造。 |
| 招牌 | 街景 | 起始店屋面向街道的招牌，也可自由放置。 |

方塊 ID、名稱、色彩和目前地形分配以 [`site/game/config.js`](../site/game/config.js) 和 [`site/game/world.js`](../site/game/world.js) 為準；本表是設計用途索引，不是另一份遊戲資料來源。

### 起始街景示例

新生成的台中起始街景包含兩間店屋、由水泥方塊排成的斑馬線示意、斑馬線旁的方塊路燈、一組方塊機車側面造型，以及使用木材和水泥搭成的街角座椅。這些都是普通可編輯方塊，沒有獨立模型或交通／通行規則。

## 原型目的地與地形

| 目的地 | 設定中的地形特色 | 目前生成方式 |
|---|---|---|
| 台灣本島（台中海岸起點） | 山脈、街角與海岸線 | 多邊形島體，中央有山脈高度輪廓；起點有街角店屋，新生成世界在中央山脊加入一座平坦石磚觀景台，以木材護欄和招牌方塊作識別。 |
| 澎湖群島 | 散落海面的玄武岩小島 | 低平的群島橢圓，地表使用石材方塊；新生成世界在主要島面加入六根可編輯石柱組成的玄武岩景物。 |
| 金門 | 島嶼聚落與海風 | 單一橢圓島體，表面形成緩丘；新生成世界加入一座石磚拼成的風獅爺示意像。 |
| 馬祖 | 北方海上的島嶼聚落 | 三個橢圓組成的群島，地表有岩脊起伏；新生成世界在主島加入石塔和小型石柱地標。 |
| 綠島 | 海蝕地形與環島小路 | 單一橢圓島體，中央地勢較高；新生成世界沿外圍生成可步行的柏油小路，北側岸緣加入一組可編輯礁岩示意。 |
| 蘭嶼 | 海洋、山林與島嶼文化 | 單一橢圓島體，南北方向形成雙峰；新生成世界沿外圍生成可步行的柏油小路，北岸加入一組可編輯礁岩示意。 |

設定中的本島起點及五個離島目的地以 [`site/game/config.js`](../site/game/config.js) 為準；高度輪廓以 [`site/game/terrain.js`](../site/game/terrain.js) 為準。表格分開記錄地形設定和實際生成方式，避免把景觀描述誤認為完整地圖功能。

中央山脊觀景台是原型內的示意座標，不對應特定真實觀景點；平台南側留有入口，並接在高度差不超過一格的地表。

綠島與蘭嶼小路及北岸礁岩、澎湖石柱、金門地標和馬祖石塔只在建立新世界或重設世界時生成；完整方塊存檔還原時會保留原存檔內容，不會自動合併新地圖方塊。

## 交通

- **船：** 交通視窗可選搭船並跳轉至本島或澎湖、金門、馬祖、綠島、蘭嶼。
- **飛機：** 交通視窗可選搭飛機並跳轉至同一組目的地。
- 兩種方式目前都以目的地跳轉呈現，沒有可駕駛載具、港口／機場設施、班次或旅行時間系統。

## 街景道具與待規劃概念

### 已實作

- 機車以既有方塊拼成側面像素造型，放在新生成的台中街角；可照一般方塊挖除、放置及復原，沒有額外互動。這不是獨立模型。

### 待規劃

- 藍白拖、球棒與遊戲用手槍目前沒有對應遊戲物件或模型；方向已定為非戰鬥展示／裝飾道具。
- 消波塊彩蛋已定為玩家自願放置的虛構景物，不捕捉或傷害角色；目前沒有對應組合、模型或互動。
- 加入實際素材前，仍需補上明確物件描述並確認素材來源；決策依據見 [`knowledge/decision.md`](decision.md)。
