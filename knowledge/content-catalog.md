# 原型內容目錄

本目錄只記錄目前原型已經有的內容，以及可供後續規劃的概念項目。概念項目不代表已實作或已決定正式版玩法。

## 方塊

| 方塊 | 分類 | 原型用途與現況 |
|---|---|---|
| 草地 | 地表 | 覆蓋多數島嶼地表，可在物品欄選取、挖除與放置。 |
| 石磚 | 岩地／建材 | 澎湖地表使用石材色塊；玩家可用來建造。 |
| 紅磚 | 建材 | 台中起始街角紅磚店屋牆面，也可自由建造。 |
| 柏油 | 街道 | 起始建築旁鋪設街道路面，可延伸街景。 |
| 木材 | 建材 | 第二間起始店屋的牆面，也可自由建造。 |
| 消波塊 | 海岸 | 起始海岸放有一排消波塊，玩家也可自由放置。 |
| 泥土 | 地層 | 用於島嶼表層以下的地層，並可由玩家選取建造。 |
| 紅瓦 | 屋頂 | 起始店屋屋頂材質，也可自由建造。 |
| 水泥 | 人行空間／建材 | 用於起始街道地坪與店屋地板，也可自由建造。 |
| 招牌 | 街景 | 起始店屋面向街道的招牌，也可自由放置。 |

方塊 ID、名稱、色彩和目前地形分配以 [`site/game/config.js`](../site/game/config.js) 和 [`site/game/world.js`](../site/game/world.js) 為準；本表是設計用途索引，不是另一份遊戲資料來源。

## 交通

- **船：** 交通視窗可選搭船並跳轉至本島或澎湖、金門、馬祖、綠島、蘭嶼。
- **飛機：** 交通視窗可選搭飛機並跳轉至同一組目的地。
- 兩種方式目前都以目的地跳轉呈現，沒有可駕駛載具、港口／機場設施、班次或旅行時間系統。

## 待規劃的在地物件

- 機車、藍白拖、球棒與遊戲用手槍是最初提出的內容例子，目前沒有對應遊戲物件或使用方式。
- 消波塊相關趣味彩蛋目前只有概念，尚未加入角色、觸發條件或動畫。
- 用途及表現方向記在 [`knowledge/decision.md`](decision.md)；加入前應先補上明確且適合原型的物件描述，避免把名稱直接當成玩法規格。
