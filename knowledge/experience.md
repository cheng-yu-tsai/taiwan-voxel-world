# 開發經驗

## 2026-11-26｜補齊觸控建造操作

- **做法：** 以 `pointer: coarse` 顯示觸控控制，沿用 Pointer Events 讓移動和跳躍可按住，並在 `pointerup`、`pointercancel` 與 `lostpointercapture` 時釋放；挖掘與放置則用可鍵盤啟動的按鈕 `click`，共用既有準星互動邏輯。
- **原因：** 原型已有觸控移動和拖曳轉向，但觸控玩家無法跳躍、挖掘或放置，建造循環因此中斷。
- **可重用範圍：** 第一人稱瀏覽器沙盒或類似的觸控遊戲；持續輸入（移動／跳躍）使用按住與釋放，單次行動（挖掘／放置）使用按鈕點擊，並依粗指標提供至少 44 CSS px 的觸控目標。
- **注意事項：** 移動按鈕必須在取消與失去指標捕捉時清除按鍵狀態，避免手指移出按鈕後角色持續移動；單次行動沿用相機準星，才會與桌面端的指向規則一致。
- **驗證：** 以 390×844、粗指標瀏覽器檢查，七個按鈕均為 46×46 CSS px，頁面沒有水平溢出；點擊挖掘和放置後方塊數依序由 5,115 降到 5,114、再回到 5,115。
- **測試限制：** 測試後以遊戲的「重設這個世界」清除測試改動時，原生 `window.confirm` 對話框使瀏覽器自動化輸入逾時，還原步驟未完成；遇到原生確認框時須用可接收瀏覽器對話框的測試控制方式，或人工完成確認。

## 2026-11-26｜讓各島地形更容易辨認

- **做法：** 將高度計算抽成無副作用的 `terrainHeight`，依島嶼設定使用固定公式；橢圓島和群島以相對中心的距離塑造坡面，不用隨機數，確保同一存檔版本每次生成一致。
- **結果：** 保留台灣本島山脈與澎湖低平地勢，新增金門緩丘、馬祖岩脊、綠島中央火山高地、蘭嶼南北雙峰；設定檔和地形函式用 Node 測試覆蓋，函式行、分支與函式覆蓋率均為 100%。
- **可重用範圍：** 原型尺度、由橢圓或少量形狀組成的島嶼地圖；固定地形公式適合小世界和可重現存檔。大型或可縮放地圖需要分區取樣或多層噪聲，避免只靠逐方塊計算。

## 2026-11-26｜用區塊索引縮小局部重建範圍

- **做法：** 用 `ChunkBlockIndex` 維護每個水平區塊所含的方塊 key；世界載入／重設後重建索引，放置和挖掘時同步更新，渲染重建只走該區塊的 key 集合。
- **原因：** 原本每次重建區塊都掃描整個方塊 Map；世界變大後，即使只挖一格，也會重複檢查其他島嶼和遠方區塊的方塊。
- **可重用範圍：** 以空間分塊、局部編輯為主的 voxel 世界；每個索引必須在初始生成、讀檔、重設、放置和刪除路徑同步更新，並以 `Math.floor` 算負座標的區塊，避免零點兩側分區錯誤。
- **驗證：** 14 項地形與索引測試通過；索引、地形與設定模組覆蓋率均為 100%。

## 2026-11-26｜讓完整方塊清單都能選用

- **做法：** 物品欄直接依設定中的方塊清單產生按鈕，數字鍵 1–9 和 0 對應十個槽位；窄螢幕使用原生水平捲動與捲動吸附，鍵盤選中遠端槽位時將它捲入可視範圍。
- **原因：** 設定已定義十種台灣街景方塊，但原型只顯示前六種，招牌、泥土、紅瓦和水泥無法從遊戲中選取。
- **可重用範圍：** 方塊數量不超過十個、希望保留簡單數字快捷鍵的建造遊戲；若清單持續變長，應改採分類、分頁或可自訂快捷鍵，而不是繼續擠壓同一列。
